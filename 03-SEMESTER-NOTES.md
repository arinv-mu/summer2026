## 🐛 Common Pitfalls & Solutions

### Python
- **Pitfall**: Forgetting to activate venv
  - **Solution**: Always check with `which python3`

- **Pitfall**: Import errors
  - **Solution**: Ensure package is in requirements.txt and installed

### Java
- **Pitfall**: Classpath issues
  - **Solution**: Use proper package structure and build tools

### C
- **Pitfall**: Memory leaks
  - **Solution**: Use valgrind to check

### C++
- **Pitfall**: Undefined reference errors
  - **Solution**: Ensure all source files are compiled
