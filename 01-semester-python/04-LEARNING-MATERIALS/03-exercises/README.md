# Python Exercises

Practice problems organized by week (weeks 1-20). Each week has 3 exercises (A, B, C) from easy to moderate difficulty.

## Folder Structure

```
03-exercises/
├── week-01-02/  (Week 1-2)
│   ├── A-hello_world.py
│   ├── B-input_output.py
│   └── C-calculator.py
├── week-03-04/  (Week 3-4)
│   ├── A-fizzbuzz.py
│   ├── B-loops.py
│   └── C-patterns.py
... and so on through week-19-20
```

## How to Use

1. **Start with Exercise A** - Usually the easiest
2. **Move to Exercise B** - Medium difficulty
3. **Challenge yourself with Exercise C** - Harder problems

## Week Breakdown

| Weeks | Topics | Concepts |
|-------|--------|----------|
| 1-2 | Basics | Variables, types, I/O, simple operations |
| 3-4 | Control Flow | if/else, loops, break/continue |
| 5-6 | Functions | Definition, parameters, returns, scope |
| 7-8 | Data Structures | Lists, dicts, sets, comprehensions |
| 9-10 | OOP Basics | Classes, objects, methods, constructors |
| 11-12 | OOP Advanced | Inheritance, polymorphism, super() |
| 13-14 | Libraries | requests, BeautifulSoup, web scraping |
| 15-16 | Data Analysis | pandas, CSV, JSON, data manipulation |
| 17-18 | Testing | pytest, unit tests, assertions |
| 19-20 | Project | Web scraper capstone (see 04-projects/) |

## Example: Week 1-2 Exercises

### Exercise A: Hello World
```python
# Print "Hello, World!"
print("Hello, World!")
```

### Exercise B: Simple Input/Output
```python
# Get user's name and greet them
name = input("What's your name? ")
print(f"Hello, {name}!")
```

### Exercise C: Simple Calculator
```python
# Add two numbers input by user
num1 = int(input("First number: "))
num2 = int(input("Second number: "))
print(f"Sum: {num1 + num2}")
```

- Test your code frequently: `python filename.py`

- Check [03-DEBUGGING-GUIDE.md](../01-guides/03-DEBUGGING-GUIDE.md) if you get errors
